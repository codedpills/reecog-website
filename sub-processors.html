Sub-Processors

Last updated: May 22, 2026

Reecog uses a limited number of third-party sub-processors to deliver our service. This page lists each sub-processor, what they do, and what data they may access.

What is a sub-processor?

A sub-processor is a third-party service that processes data on our behalf to help deliver Reecog's functionality.

Our sub-processors

Sub-processor Purpose Location Data processed
Railway Application hosting and database infrastructure United States All application data (encrypted at rest and in transit)
LemonSqueezy Subscription billing and payment processing United States Workspace subscription identifiers, plan selections, payment details
GIPHY GIF retrieval for recognition celebrations United States Search keywords based on company values only; no user data is transmitted

Our commitments

  • Minimal data sharing — We only share data with sub-processors that is strictly necessary for their function. No user personal data, message content, or recognition records are shared with any sub-processor.
  • Encryption — All data transmitted to sub-processors is encrypted in transit via TLS. Database storage on Railway uses SSL-encrypted connections.
  • No selling of data — We never sell, rent, or trade user data to any third party.
  • Contractual protections — Each sub-processor is bound by data processing agreements that require them to protect data in accordance with applicable privacy laws.

Changes to this list

We will update this page when we add or remove sub-processors. If a change materially affects how personal data is processed, we will notify affected workspace administrators via the app.

Questions?

If you have questions about our sub-processors or data handling practices, contact us at support@reecog.com.
